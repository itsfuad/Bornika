## Added

- **Escape** cancels active composition and hides its preedit.
- **Tab** commits the complete translated composition without adding whitespace or changing focus. With no composition, Tab passes through normally; **Shift + Tab** remains available for backward focus navigation.
- **Left / Right** move through the original phonetic input; **Home / End** select its boundaries. Inside a multi-letter match such as `kh`, the rendered caret snaps to the token's leading boundary.
- Typing inserts at the source cursor, **Backspace** removes the preceding input character, and **Delete** removes the following one. Boundary no-ops are consumed while composition is active.
- Normal and keypad navigation/Delete aliases are supported. Modified controls, control-key releases, and controls in empty-composition or English mode pass through.

## Fixed

- IBus underline attributes now use unsigned Unicode-character offsets, matching the wire protocol and rendered caret units.
- Translation and caret mapping share one contextual token parser; source edits stay on UTF-8 boundaries.
- Composition-control modifier handling uses one shared classification across the engine and IBus decoder.

## Library API migration (breaking)

The `bornika-phonetic` public API changes in this release:

- Replace `PhoneticEngine::new()` with `PhoneticEngine::default()`.
- `Default` now starts with **Bangla enabled**. Callers that previously relied on an English-mode default must explicitly set `engine.bangla_mode = false`.
- `push_char` and `pop_char` are removed. Drive edits through `process_key_event` with `VirtualKey::Char`, `VirtualKey::Backspace`, or `VirtualKey::Delete` and explicit modifier/release flags. Edits operate at the current source cursor rather than always at the buffer's end.
